# RavenFuel 🖤

> Premium Gym Supplements Store — Built with Antigravity & Deployed on Vercel

---

## 📌 About

RavenFuel is a fully functional e-commerce website for premium gym supplements. It features product listings, category browsing, and an AI-powered chatbot assistant to help customers find the right supplements for their fitness goals.

---

## 🚀 Live URL

🔗 [https://ravenfuel.vercel.app](https://ravenfuel.vercel.app)

---

## 🛠️ Built With

- **Antigravity** — Frontend Framework
- **Vercel** — Deployment & Hosting
- **Chatbase** — AI Chatbot Integration

---

## ✨ Features

- 🏠 Hero section with animated stats
- 🛒 Product cards with SVG illustrations
- 📦 Category browsing (Whey, Creatine, Pre-Workout, etc.)
- 🤖 AI Chatbot (FuelFit Agent) powered by Chatbase
- 📱 Fully responsive design
- 🎨 Dark theme with orange accent

## 🤖 Chatbot

Integrated **Chatbase AI Agent** trained on RavenFuel's product catalog. The chatbot can:
- Recommend supplements based on fitness goals
- Answer questions about brands and products
- Provide pricing, shipping, and discount info
- Reply in English or Hinglish
